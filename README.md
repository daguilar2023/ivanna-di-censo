# Ivanna di Censo — Portfolio

A Spanish-language fashion design and communication portfolio, created from Ivanna's supplied profile, project imagery, and visual references.

## Run locally

No package installation or build step is required. With Python installed:

```sh
python3 -m http.server 4173
```

Open http://localhost:4173. GitHub Pages publishes the root of `main`.

## Edit

- `index.html`: introduction and selected projects
- `sobre-mi.html`: biography, education, experience, tools, languages
- `hay-alguien-en-casa.html`, `uniqlo-flower.html`, `match-and-martini.html`: project pages
- `assets/style.css`: responsive design and color/typography tokens
- `assets/main.js`: project filters and keyboard-accessible image viewer
- `assets/images/`: optimized WebP images extracted from the supplied portfolio
- `assets/ivanna-di-censo-portfolio.pdf`: original downloadable portfolio

The site uses semantic HTML, CSS and small progressive enhancements in JavaScript. Navigation and project content remain usable without JavaScript. Fonts are self-hosted. No analytics, cookies, server, form processing or third-party scripts are included.

Concept projects are labeled as proposals. UNIQLO Flower is an independent concept, not presented as a commercial collaboration. Photography credits are shown on the corresponding project pages.

## Design guidance

The provided inspiration sets the visual direction: warm paper, spacious editorial layouts, a small rust accent, asymmetric image compositions. UI/UX Pro Max informed contrast, focus, image sizing, touch interactions and reduced-motion support.

Fonts: DM Sans and Instrument Serif (SIL Open Font License; licenses in `assets/fonts`). Portfolio content and imagery remain the property of their respective creators.
